# 📚 Library Management System

A responsive Library Management System built using **HTML, CSS, and JavaScript**. This application allows users to manage books efficiently with features like adding, editing, deleting, searching, and borrowing/returning books. All data is stored in the browser using **Local Storage**, ensuring it persists even after refreshing the page.

## ✨ Features

* Dashboard with library statistics
* Add, edit, and delete books
* Search books by title or author
* Filter books by category and availability
* Borrow and return books
* Category management
* Responsive design for all devices
* Dark/Light mode
* Data persistence using Local Storage

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Double-click `index.html` or open it in your preferred web browser.
